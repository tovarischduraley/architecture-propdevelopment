# Обоснование выбора разделов

## Безопасность данных (Высокий приоритет) – Обоснование  
Компания сталкивается с серьёзными трудностями в контроле над данными.  
Поступают жалобы от клиентов на случайное отображение чужой персональной информации.  
Требуется проверка на соответствие законодательству в области обработки персональных данных.  
Планы по развитию сервисов, основанных на данных, нуждаются в надёжной системе защиты.

### Область внимания  
- Потоки передачи данных между системами  
- Методы обезличивания и защиты персональных данных  
- Контроль доступа к базам данных  
- Соответствие нормативным требованиям  

## Управление доступом (Высокий приоритет) – Обоснование  
Отсутствует систематический контроль доступа к информации.  
Существуют риски несанкционированного доступа к данным клиентов.  
Проблемы с API партнёров, дающие избыточные права.

### Область внимания  
- Политики разграничения доступа  
- Механизмы аутентификации и авторизации  
- Контроль прав доступа для сторонних систем  
- Управление учётными записями  

## Управление инцидентами (Средний приоритет) – Обоснование  
Руководство обеспокоено возможными утечками информации.  
Необходимы процессы для оперативного реагирования на угрозы.  
Требуется подготовка к возможным инцидентам в области безопасности.

### Область внимания  
- Процедуры выявления и реагирования на инциденты  
- Механизмы мониторинга безопасности  
- План восстановления после инцидентов  
- Документирование и анализ инцидентов  

## Защита инфраструктуры (Средний приоритет) – Обоснование  
Используются собственные серверы и гибридная инфраструктура.  
Требуется всесторонняя защита IT-окружения.  
Существуют интеграции с внешними системами.
